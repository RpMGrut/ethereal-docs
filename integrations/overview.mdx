ethereal — OpenAI-совместимый шлюз, поэтому подходит почти любой инструмент, где
можно задать **base URL** и **API-ключ**. Принцип везде одинаковый.

## Что подставлять

| Тип клиента | Base URL | Ключ |
| --- | --- | --- |
| OpenAI-совместимые (Cursor, Cline, Continue, Aider, Zed, OpenAI SDK) | `https://api.ethereal.llc/v1` | `eth-...` |
| Claude Code (Anthropic CLI) | `https://api.ethereal.llc` | `eth-...` |

Универсальные переменные окружения:

```bash
# OpenAI-совместимые инструменты
export OPENAI_BASE_URL="https://api.ethereal.llc/v1"
export OPENAI_API_KEY="eth-..."

# Anthropic-стиль (Claude Code)
export ANTHROPIC_BASE_URL="https://api.ethereal.llc"
export ANTHROPIC_API_KEY="eth-..."
```
