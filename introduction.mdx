**ethereal** — это шлюз к моделям Claude (Opus, Sonnet, Haiku) через единый
**OpenAI-совместимый** эндпоинт. Подключаешь любой привычный SDK или CLI,
меняешь `base_url` — и работаешь. Оплата по **СБП или криптой**, без карт и без
VPN, с прозрачным списанием за токены.

<CardGroup cols={2}>
  <Card title="Без подписки" icon="infinity">
    Платишь только за использованные токены. Никаких ежемесячных списаний и
    автопродлений — баланс не сгорает.
  </Card>
  <Card title="Прозрачный биллинг" icon="receipt">
    Списание за каждый запрос по тарифу модели (input/output). Полная разбивка
    в личном кабинете.
  </Card>
  <Card title="Оплата из России" icon="ruble-sign">
    СБП или криптовалюта — без VPN и иностранных карт.
  </Card>
  <Card title="OpenAI-совместимость" icon="plug">
    Drop-in замена: тот же формат запросов, что у OpenAI Chat Completions.
    Работает с популярными SDK и dev-инструментами.
  </Card>
</CardGroup>

## Для кого

- Разработчики, использующие Claude в коде, CLI и агентах (Claude Code, Cursor, Cline, Aider…).
- Команды, которым нужен общий ключ с единым биллингом.
- Пользователи из РФ, которым удобнее платить локально.

## Базовый URL

```
https://api.ethereal.llc/v1
```

## Как начать

<Steps>
  <Step title="Создай аккаунт">
    Зарегистрируйся на [ethereal.llc/register](https://ethereal.llc/register) —
    логин и пароль, без почты.
  </Step>
  <Step title="Пополни баланс">
    Купи пакет токенов (от 5M за 99 ₽) или пополни на любую сумму. Оплата по СБП
    или криптой. См. [Тарифы](/pricing).
  </Step>
  <Step title="Создай API-ключ">
    В [кабинете](https://ethereal.llc/dashboard) сгенерируй ключ вида `eth-…`.
    См. [Авторизация](/authentication).
  </Step>
  <Step title="Подключи в коде">
    Укажи `base_url: https://api.ethereal.llc/v1` и свой ключ. См.
    [Быстрый старт](/quickstart).
  </Step>
</Steps>

<Note>
  ethereal не аффилирован с Anthropic. Claude и связанные товарные знаки
  принадлежат их владельцам.
</Note>
